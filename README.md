# Diffusion Transformers · AIMS Camaleão

Slides em HTML da apresentação **Introdução aos Diffusion Transformers (DiTs)**, de Johsac Isbac Gomez Sanchez, no Grupo de Estudos Camaleão ([AIMS] Artificial Intelligence through Multimodal Signal Processing).

Baseado no artigo W. Peebles, S. Xie. *Scalable Diffusion Models with Transformers.* ICCV 2023.

## Como abrir

Abra `index.html` no navegador (a pasta `img/` precisa estar ao lado).

- `→` / espaço: avançar · `←`: voltar · `F`: tela cheia
- `index.html#N` abre direto na lâmina N
